# Data directory

Cached public samples and the synthetic donation ledger live here.

The repository currently ships the run contract only. Sample payloads for FDA
enforcement, FDA adverse events, a second agency notice set, Open Food Facts,
and the synthetic donation ledger are added when the data layer caches query
results.

## Licence notes (required when samples arrive)

- **Open Food Facts** — Open Database Licence (ODbL). Attribution and
  share-alike apply. Cite Open Food Facts contributors in the product README
  and here: https://world.openfoodfacts.org/data
- **FDA open APIs** — public government data; cite the endpoint used.
- **Donation ledger** — synthetic, generated locally rather than exported from
  any real system; labelled synthetic with record count and limitations.

No PII. No confidential records.
